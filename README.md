# LumiRPEngine

RPE (RPEngine) is an application for roleplay with AI models that runs beside Lumiverse. This repository holds its built files, the ones Lumiverse installs. The source is at https://github.com/TheLiquorPriest/RPEngine.

## Install

In Lumiverse: **Extensions**, **Add Extension**, **Install from Source**, this repository's address, and a branch.

| Branch | What it holds |
|---|---|
| `alpha` | alpha builds |
| `dev` | beta builds and release candidates, once there is one |
| `main` | stable releases, once there is one |

There is no stable release yet, so this branch holds only this page. Install the branch `alpha`; the README on that branch says how to set RPE up.

Each build is tagged with its version, for example `v3.1.1.17.00-alpha`.
