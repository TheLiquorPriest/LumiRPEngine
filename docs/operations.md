# The engine's operations

Generated by `bun scripts/operations.ts` from the engine's tools as `src/iface/` registers them and their files in `guidance/.tools/`. Do not edit it by hand: change a tool or its file and run the script again (`--check` says whether this file is current).

13 everyday operations and 41 searchable tools.

## Everyday operations

Each is one item of `world_apply`'s `operations` list, named by `op`. A call's operations are applied in order and recorded in one write; a later one may name what an earlier one made.

An operation whose entry says it takes its provenance takes these three arguments:

| Argument | Shape | What it is |
|---|---|---|
| `source` | object: from, lore, message, roll, gap_check, consent | Where it comes from (horizon takes none): from is prose, lore, author, gm, character, player, default or invented; lore, message and roll cite an entry, a message or a roll by id; an invention cites its gap_check and consent. |
| `precision` | one of exact, approximate, vague, unknown | How exact: exact, approximate, vague or unknown. |
| `standing` | one of established, proposed, assumed | How it stands: established, proposed or assumed. |

### move

someone or something goes to a place, with others along.

Lane: engine. Needs: `who`, `to`. Takes its provenance.

| Argument | Shape | What it is |
|---|---|---|
| `who` | text | move: who or what goes. wear: who wears it. pay: who pays. relate: whose regard changes. |
| `to` | text | move: the place. give: who receives it. pay: who is paid; leave it out for no one in the world. relate: whom they regard. |
| `with` | list of text | move: others who go along. |
| `square` | list of whole number | move, place: the square on the place's map, as [column, row], counted from 1 at the top left as the map prints it. |
| `near` | text | move, place: someone or something to stand beside on the place's map. |
| `zone` | text | move, place: a zone of the place's map. |
| `why` | text | move, place, give, store, quest, relate: the reason, kept with the change. |

Worked example:

```json
{

    {
      "op": "move",
      "who": "bram",
      "to": "market_square",
      "with": [
        "odile"
      ],
      "source": {
        "from": "prose",
        "message": "m-0012"
      },
      "standing": "established"
    }
  ]
}
```
